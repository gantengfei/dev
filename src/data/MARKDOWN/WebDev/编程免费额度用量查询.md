
# ■ GitHub Copilot

登录 [**GitHub**](https://github.com) ➥ 右上角个人LOGO中选择 **Settings** ➥ [**GitHub Copilot**](https://github.com/settings/copilot/features) 免费的额度用量查询。

![输入图片说明](./src/img/images/2026-06-10_10-48-33.png "")

> 微软 **‌GitHub Copilot** 免费版每月给 **2000** 次代码补全和 **50** 次聊天‌，所有注册用户都能用，额度按月刷新。‌‌‌
> - ‌代码补全‌：每月 ‌**2000** 次‌，写代码时自动提示算一次。
> - ‌AI 聊天‌：每月 ‌**50** 次‌，在对话框问问题算一次。
> - ‌刷新规则‌：额度每月自动重置，没用完的不会攒到下个月。‌‌‌

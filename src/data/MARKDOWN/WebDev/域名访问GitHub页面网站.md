# 自定义/个人域名绑定到GitHub仓库

## ❑ 域名解析配置（新网配置）

1、登录[**新网控制台**](https://console.xinnet.com/)，找到购买的域名并进入 **域名解析** 页面。

![输入图片说明](./src/img/images/2026-07-03_15-29-06.png "")

2、点击 **解析** 按钮，点击 **添加记录** 按钮。

3、记录类型选择 **CNAME**，主机记录填写 `@` / `*`，记录值填写 `xxx.github.io`，TTL 默认选择 **10分钟**。

![输入图片说明](./src/img/images/2026-07-03_15-36-25.png "")
![输入图片说明](./src/img/images/2026-07-03_15-37-58.png "")


## ❑ GitHub仓库设置配置自定义域名

1、打开托管 **GitHub Pages** 的仓库，点击页面顶部的 **Settings**（设置），在左侧菜单找到并点击 **Pages**。

2、在 **Custom domain** 输入框中，填入完整自定义域名（例如 `www.example.com` 或 `example.com`），然后点击 **Save**。

![输入图片说明](./src/img/images/2026-07-03_15-46-25.png "")

3、添加 CNAME 文件：确保在 **GitHub** 仓库根目录下存在一个名为 **CNAME** 的文件（无后缀名），文件内容仅包含您的自定义域名。

**注意：**如果您使用 Hexo、Hugo 等静态博客框架，请务必将 **CNAME** 文件放在源码目录下，防止每次自动编译部署时被清空。

## ❑ 验证与启用HTTPS（可选）

1、保存设置后，**GitHub** 会自动检查您的 **DNS** 配置。如果配置正确，输入框下方会出现绿色的成功提示。**DNS** 解析的全球同步通常需要几分钟到 48 小时。

2、确认域名配置成功后，在同一个 **Pages** 设置页面中，勾选 **Enforce HTTPS**（强制使用 HTTPS）选项。**GitHub** 会自动为您的域名签发免费的 **SSL** 证书（此过程可能需要几分钟到几个小时）。

完成以上步骤后，您就可以通过自己的自定义域名访问 **GitHub Pages** 网站了。

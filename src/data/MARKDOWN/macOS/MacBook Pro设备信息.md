# ✅ MacBook Pro

## 💻 设备信息

**MacBook Pro(13-inch，2016，Four Thunderbolt 3 Ports)**

> MacBook Pro（13 英寸，2016，四个 Thunderbolt 3 端口） \
> 这是苹果在 2016 年 10 月发布的一代标志性产品，首次引入了 Touch Bar 和 全 USB-C/Thunderbolt 3 接口设计。

## 🔍 基础规格

| 项目      | 参数                                                                       |
| --------- | -------------------------------------------------------------------------- |
| 型号标识  | MacBookPro14,3                                                             |
| 发布时间  | 2016 年 10 月 27 日（国行 2016 年 11 月 2 日开售）                         |
| 屏幕      | 13.3 英寸 Retina（2560×1600，P3 广色域，500 尼特亮度）                     |
| 处理器    | 双核 Intel Core i5/i7（基础频率 2.9GHz / 3.3GHz，Turbo Boost 最高 3.8GHz） |
| 内存      | 8GB 或 16GB LPDDR3（板载，不可升级）                                       |
| 存储      | 256GB / 512GB / 1TB PCIe SSD（不可自行更换）                               |
| 显卡      | Intel Iris Graphics 550                                                    |
| 接口      | 4 个 Thunderbolt 3（USB-C），支持充电、DisplayPort、USB 3.1 Gen 2          |
| 其他      | Touch Bar + Touch ID、Force Touch 触控板、720p FaceTime 摄像头             |
| 重量/厚度 | 1.37 kg / 14.9 mm                                                          |
| 电池续航  | 官方标称 10 小时无线网页浏览                                               |

## 💻 系统兼容性（截至 2026 年）

| macOS 版本                       | 是否支持        | 说明                                                                                                         |
| -------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------ |
| macOS Monterey (12)              | ✅ 官方支持     | 最后一个完整支持 Intel 2016 款的版本                                                                         |
| macOS Ventura (13)               | ⚠️ 非官方支持 | 可通过 [OpenCore Legacy Patcher](https://dortania.github.io/OpenCore-Legacy-Patcher/) 安装，但存在兼容性风险 |
| macOS Sonoma (14) / Sequoia (15) | ❌ 不支持       | 官方最低要求为 2018 年及以后机型                                                                             |

# 安装 TypeScript

安装 `TypeScript`
``` bash
sudo npm install -g typescript
```

安装 `TypeScript@2.7.2`
``` bash
sudo npm install -g typescript@2.7.2
```

卸载 `TypeScript`
``` bash
sudo npm uninstall -g typescript
```

查看 `tsc` 版本
``` bash
tsc -v
```

查看 `tsc` 当前的安装路径
``` bash
which tsc
```

`npm` 检查全局包列表
``` bash
npm list -g --depth=0
```

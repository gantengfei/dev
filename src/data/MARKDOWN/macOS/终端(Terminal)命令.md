# 安装 TypeScript

安装 TypeScript
``` bash
sudo npm install -g typescript
```

安装 TypeScript@2.7.2
``` bash
sudo npm install -g typescript@2.7.2
```

卸载 TypeScript
``` bash
sudo npm uninstall -g typescript
```

查看版本
``` bash
tsc -v
```

查看当前 tsc 的安装路径
``` bash
which tsc
```

npm 检查全局包列表
``` bash
npm list -g --depth=0
```

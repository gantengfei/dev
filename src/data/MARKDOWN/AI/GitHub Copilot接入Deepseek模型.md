
在 **Copilot Chat** 模型选择器中直接使用 **DeepSeek V4**——无需离开你熟悉的 **Copilot** 工作流。

# ➤ 安装扩展
- 1、打开 **VSCode**
- 2、安装 **DeepSeek V4 for Copilot Chat** 扩展

![输入图片说明](./src/img/images/2026-10-09_09-38-13.png "")

# ➤ 使用 Deepseek 模型
- 1、[**Deepseek 开发平台**](https://platform.deepseek.com/) 创建 **API keys** 复制妥善保存
- 2、通过命令面板（`Cmd+Shift+P`）运行 **DeepSeek: 设置 API Key**
- 3、粘贴 **Key**（官方 DeepSeek Key 通常以 `sk-` 开头）
- 4、打开 **Copilot Chat**，点击模型选择器，选择 **DeepSeek V4 Flash** 或 **DeepSeek V4 Pro**

![输入图片说明](./src/img/images/2026-10-09_09-32-45.png "")

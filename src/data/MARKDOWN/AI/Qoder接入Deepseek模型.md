[**Qoder CN**](https://qoder.com.cn/) 是 **阿里** 推出的 **智能体工作台**

# ➤ 使用 Deepseek 模型

- 1、[**Deepseek 开发平台**](https://platform.deepseek.com/) 创建 **API keys** 复制妥善保存
- 2、打开 **Qoder CN** 桌面版，登录个人账号
- 3、在 **Qoder CN** 桌面版中，点击 **设置** 菜单，选择 **模型** 模块
- 4、点击 **添加模型** 按钮
- &emsp;● **供应商**： **DeepSeek**
- &emsp;● **模型**： 全选 (**deepseek-v4-pro**、**deepseek-v4-flash**)
- &emsp;● 填写 **API keys**
- 5、点击 **校验并添加模型**

![输入图片说明](./src/img/images/2026-10-09_09-16-18.png "")

- 6、模型添加成功

![输入图片说明](./src/img/images/2026-10-09_09-16-48.png "")

- 7、在 **Qoder CN** 桌面版中，点击 **模型** 自定义，选择 **deepseek-v4-pro** 或 **deepseek-v4-flash**

![输入图片说明](./src/img/images/2026-10-09_09-20-17.png "")

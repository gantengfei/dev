在 **CSS** 中，`inherit`、`revert`、`initial` 和 `unset` 是四个用于控制属性继承和重置的全局关键字。它们的核心区别在于对属性值的处理方式不同：

- `inherit`：强制元素继承其父元素的计算值。
- `initial`：将属性重置为 **CSS** 规范中定义的初始值（与浏览器默认样式无关）。
- `revert`：将属性重置为浏览器默认样式表（User Agent Stylesheet）或用户自定义样式中设定的值。
- `unset`：智能重置。如果属性默认是可继承的，则等同于 `inherit`；如果不可继承，则等同于 `initial`。

# 详细解析与对比
## 1. inherit（继承）

- ● **作用：**使当前元素的属性值与其父元素的计算值完全相同。
- ● **特点：**无论该属性在 CSS 规范中是否默认可继承，使用 `inherit` 都会强制其继承父级样式。
- ● **示例：**`color: inherit;` 会让元素的文字颜色与父元素保持一致。

## 2. initial（初始值）

- ● **作用：**将属性重置为 CSS 规范中定义的初始默认值。
- ● **特点：**它忽略所有继承和层叠规则，且这个初始值对所有元素都是一样的，不区分元素类型。例如，`display` 属性的初始值是 `inline`，即使应用在 `<div>` 上，它也会变成行内元素，而不是浏览器默认的块级元素。

## 3. revert（恢复默认）

- ● **作用：**回滚当前样式，将属性恢复到浏览器默认样式表（或用户样式表）设定的值。
- ● **特点：**与 `initial` 不同，`revert` 尊重浏览器针对特定元素的默认设定。例如，对 `<div>` 使用 `display: revert;` 会恢复为浏览器默认的 `block`。它常用于清除自定义样式，还原元素的原生外观。

## 4. unset（未设置/智能重置）

- ● **作用：**根据属性本身的继承特性来决定重置方式。
- ● **特点：**
- &emsp;● 对于可继承属性（如 `color`、`font-family`），它的行为等同于 `inherit`。
- &emsp;● 对于不可继承属性（如 `border`、`display`），它的行为等同于 `initial`。
- **● 场景：**常用于需要同时处理继承与非继承属性的通用样式重置（如配合 `all` 属性使用）。

# 核心区别

| 关键字 | 核心行为 | 是否依赖属性的继承性 | 典型应用场景 |
| :--- | :--- | :--- | :--- |
| `inherit` | 强制继承父元素的值 | 否（强制继承） | 让原本不继承的属性（如 `border`）也继承父级 |
| `initial` | 重置为 CSS 规范初始值 | 否 | 组件库开发，需要完全覆盖外部样式，精确控制到规范定义 |
| `revert` | 恢复为浏览器默认样式 | 否 | 清除自定义样式，还原 `<button>`、`<h1>` 等元素的原生表现 |
| `unset` | 可继承则继承，不可继承则取初始值 | 是 | 通用样式重置（如 `all: unset`），快速清除样式但保留合理继承 |

以上四个关键字都可以配合 **CSS** 简写属性 `all` 使用（例如 `all: unset;`），从而一次性将元素的所有属性（除 `unicode-bidi` 和 `direction` 外）重置到对应的状态。

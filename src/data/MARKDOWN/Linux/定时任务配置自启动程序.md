# GeoServer 自启动

1.**创建一个脚本**，脚本名称为 `geoserver.sh`，内容如下：

``` bash
#!/bin/bash
#配置环境变量
export GEOSERVER_HOME=/home/apps/geoserver-2.16.1

ID=`ps -ef | grep geoserver  | grep -v "$0" | grep -v "grep" | awk '{print $2}' `
if [ $ID ]
then
echo "Geoserver Running....."
else

nohup /home/apps/geoserver-2.16.1/bin/startup.sh > /home/apps/geoserver-2.16.1/bin/myLog.log 2>&1 &

fi
```

**注意：**文件格式 **UNIX**

``` bash
vim /home/xxx.sh
#ESC键
:set ff
#看见 该文件的格式 fileformat=dos
:set ff=unix
#查询确认是否unix类型
:set ff
#退出 Shift + zz
```

2.**设置脚本权限**

``` bash
chmod 777 /home/apps/geoserver-2.16.1/bin/startup.sh
```

或 右键 `tomcatStart.sh` 文件 > 属性 > 更改权限 > 文件/文件夹 权限：`777`

![输入图片说明](./src/img/images/2026-06-25_09-29-52.png "")

3.**创建定时任务**

每 **5** 分钟执行一次 `geoserver` 的启动/管理脚本

``` bash
crontab -l #查询规则
crontab -e #修改规则
# i键进入编辑状态
*/5 * * * * /bin/sh /home/apps/geoserver-2.16.1/geoserver.sh
# esc退出编辑状态
:wq!

# 测试geoserver.sh 是否生效
cd /home/apps/geoserver-2.16.1
sh geoserver.sh
# Running.....
```

# Tomcat 自启动

1.**创建一个脚本**，脚本名称为 `tomcatStart.sh`，内容如下：

``` bash
#!/bin/bash
#配置环境变量
export CATALINA_HOME=/home/apache-tomcat-8.5.100

ID=`ps -ef | grep tomcat  | grep -v "$0" | grep -v "grep" | awk '{print $2}' `
if [ $ID ]
then
echo "tomcat Running....."
else

/home/apache-tomcat-8.5.100/bin/startup.sh

fi
```

**注意：**文件格式 **UNIX**

2.**设置脚本权限**

``` bash
chmod 777 /home/apache-tomcat-8.5.100/tomcatStart.sh
```

或 右键 `tomcatStart.sh` 文件 > 属性 > 更改权限 > 文件/文件夹 权限：`777`

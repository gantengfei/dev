# vite打包

## 1. 安装依赖包

``` Bash
npm i vite-bundle-visualizer --D
```

## 2. 新增配置

在`package.json`中加入命令

### `-t treemap` 树状图（默认）
``` JSON @package.json
scripts: {
  "visualizer": "vite-bundle-visualizer"
}
```

### `-t sunburst`  环形图
``` JSON @package.json
scripts: {
  "visualizer": "vite-bundle-visualizer -t sunburst"
}
```

### `-t network` 网络图
``` JSON @package.json
scripts: {
  "visualizer": "vite-bundle-visualizer -t network"
}
```

### `-t raw-data` 原始数据
``` JSON @package.json
scripts: {
  "visualizer": "vite-bundle-visualizer -t raw-data"
}
```

### `-t list` 列表
``` JSON @package.json
scripts: {
  "visualizer": "vite-bundle-visualizer -t list"
}
```


## 3. 运行打包命令

``` Bash
npm run visualizer
```
